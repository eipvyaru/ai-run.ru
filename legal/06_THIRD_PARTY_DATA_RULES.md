# ПРАВИЛА ПЕРЕДАЧИ И ОБРАБОТКИ ПЕРСОНАЛЬНЫХ ДАННЫХ ТРЕТЬИХ ЛИЦ

Версия: **1.0.0**  
Дата вступления в силу: **01.11.2026**

## 1. Общие положения

Настоящие Правила относятся к материалам, которые Пользователь передаёт через сайты **ai-run.ru** и управляемые поддомены **`*.ai-run.ru`**, если они содержат сведения о других физических лицах. Функция Cover Letter (`https://cover-letter.ai-run.ru`) в Release 2 рассчитана на B2C и подготовку писем для собственного трудоустройства; технически он не проверяет правообладателя, автора и субъектный состав загруженного резюме.

## 2. Правомерность предоставления

Пользователь вправе предоставлять сведения других лиц только при наличии соответствующего законного основания и полномочий; не следует использовать общедоступность документа как автоматическое подтверждение безусловного разрешения на любую последующую обработку. Пользователь самостоятельно оценивает законность получения и передачи, но **его заверения не освобождают Оператора от собственных обязанностей** по защите и законному режиму обработки. Согласие Пользователя за себя не является согласием третьего лица.

## 3. Минимизация

Передавать только сведения, необходимые для конкретной функции; для Cover Letter — для подготовки сопроводительного письма. Не размещать пароли, секреты, паспортные сканы, финансовые реквизиты, точные домашние адреса и другие лишние идентификаторы. Пользователю рекомендуется самостоятельно убрать из материалов данные третьих лиц, не относящиеся к задаче.

## 4. Специальные категории и биометрические данные

Не передавать данные о здоровье, убеждениях, биометрические и иные сведения специального правового режима без самостоятельно подтверждённых законных оснований и оценки допустимости обработки. Обычная функция не предназначена для отдельного сбора таких данных. Сервис не обеспечивает сплошную автоматическую фильтрацию и не гарантирует обнаружения каждой категории; техническая возможность отправить текст не является правовым разрешением.

## 5. Данные несовершеннолетних

Передача таких сведений требует применимого законного основания и необходимых полномочий. Не отправлять без такой проверки.

## 6. Передача поставщикам LLM

В режиме **Cover Letter Release 2** **исходные** резюме, вакансии и пожелания могут передаваться непосредственно **Yandex AI Studio** либо **Cloud.ru Foundation Models / GigaChat** без предварительного обезличивания для генерации и Quality Check. Если в тексте есть данные третьего лица, они также могут войти в запрос. Договорные участники указаны в **https://ai-run.ru/legal/privacy**. По подтверждению OWNER используемая схема обработки расположена в РФ и не предусматривает трансграничной передачи. Согласие Пользователя за себя не заменяет правового основания в отношении третьих лиц.

## 7. Обращения субъектов ПДн

Субъекты вправе обращаться по **info@ai-run.ru** с предусмотренными законом запросами. Оператор рассматривает обращения и может запросить достаточные сведения для установления предмета запроса, без избыточного раскрытия иных персональных данных; при необходимости действовать по утверждённым процедурам ограничения и удаления.

## 8. Профессиональное использование

Использование **Cover Letter** как обработчика по поручению профессионального оператора (работодателя, кадрового агентства и др.) в его B2C Release 2 не предусмотрено. Для других сервисов AI-RUN условия профессионального использования определяются отдельно. Отдельный договор, поручение по ч.3 ст.6 152-ФЗ, обязанности и список субподрядчиков возможны только по отдельной спецификации и приёмке.

Контакт по ПДн: **info@ai-run.ru**.
