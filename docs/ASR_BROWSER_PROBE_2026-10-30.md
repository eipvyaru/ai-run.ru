# Пробный запуск ASR: браузер и GigaAM punct

Дата: 30.10.2026  
Статус: **техническая проба; точность вариантов не сравнена**.

## Материал и условия

Использован один опубликованный WAV из комплекта `sherpa-onnx-nemo-transducer-punct-giga-am-v3-russian-2025-12-16/test_wavs/example.wav`: PCM16, mono, 16 кГц, 11,29 секунды. Это контрольный пример модели, а не запись участника и не тестовый набор из `ASR_TEST_PLAN.md`.

Локальный прогон выполнен на Windows, Python 3.14.6, sherpa-onnx 1.13.8, CPU, 2 потока. Прогрев модели не учитывался в медиане. Три повторных декодирования дали медиану около **1,03 с** (RTF около **0,091**). Текст повторялся одинаково:

> Ничего не требуя похвал, Счастлив уж я надеждой сладкой, Что дева с трепетом любви Посмотрит, может быть, украдкой На песни грешные мои. У лукоморья дуб зелёный,

У WAV нет независимой эталонной расшифровки в комплекте, поэтому по этому примеру нельзя посчитать WER или подтвердить точность. Конец распознанного текста может быть неполным относительно исходного WAV.

## Браузерная проба

Тот же WAV был подан в изолированную страницу через `SpeechRecognition.start(audioTrack)` с `ru-RU` и параметрами текущего ввода. Браузер завершил запрос ошибкой **`network`**. Расшифровки нет; этот результат не является ошибкой распознавания и не позволяет сравнить точность.

Текущий интерфейс приложения использует микрофонный `SpeechRecognition.start()` без аудиотрека. Изолированная проба дополнительно проверила вариант подачи одного файла в браузер. Сбой показывает, что в текущей среде браузерный распознаватель недоступен по сети. Он также подтверждает зависимость Web Speech API от браузерного сервиса, а не работу локальной GigaAM.

## Вывод

- Локальная модель обработала данный WAV быстрее его длительности на этом компьютере.
- Это не измерение пользовательской задержки, не оценка VPS и не доказательство превосходства модели по качеству.
- Парное сравнение точности остаётся невыполненным. Для него нужны записи по плану с проверенной эталонной расшифровкой и доступный браузерный сервис либо согласованный браузер, который может принять аудиотрек.
- Модель не подключена к приложению или VPS; продакшен не менялся.
