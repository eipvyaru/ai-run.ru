# Сравнение вариантов распознавания речи

Дата: 31.10.2026  
Статус: **оценка вариантов завершена по доступным данным; прямой парный тест точности не состоялся**.

## Краткий вывод

Для локального кандидата следует оставить `sherpa-onnx-nemo-transducer-punct-giga-am-v3-russian-2025-12-16`. Он работает автономно, содержит токены цифр и пунктуации, а локальный прогон на компьютере укладывается в длительность записи. Это делает его более контролируемым вариантом по месту обработки и доступности.

Доказательств, что он распознаёт речь точнее текущего браузерного ввода, пока нет. В браузерной пробе Web Speech API вернул `network`; получить его текст для того же аудио не удалось. У контрольного WAV из пакета модели нет независимого эталона, поэтому оценить точность GigaAM на нём также нельзя. Результаты ограниченной пробы приведены в [отчёте](ASR_BROWSER_PROBE_2026-10-30.md).

## Независимые данные производителя

В upstream-оценке семейства GigaAM v3 для RNNT сообщён средний WER 8,3% на наборе русских доменов. В таблице опубликованы, в частности, 9,5% для Callcenter, 17,4% для OpenSTT Phone Calls и 0,9% для Mozilla Common Voice 19. Разница между доменами существенна. Эти числа относятся к оценке автора семейства GigaAM и не являются измерением текущего ONNX-файла на речи пользователей AI-Run; метрика Web Speech API рядом с ними не опубликована и здесь не измерена.

## Решение

1. В каталоге локальных моделей оставлена одна версия — `punct`.
2. В качестве кандидата для собственного ASR далее рассматривать GigaAM punct: он даёт локальную обработку и уже показал достаточную скорость на тестовом компьютере.
3. Не считать его точность выше браузерной и не заменять текущий микрофонный ввод до парного теста на одних WAV с эталонными расшифровками.
4. Не переносить локальный результат на VPS. Перед подключением к приложению отдельно измерить установку модели, память, CPU, очереди и задержку на VPS.

## Что означает завершение сравнения

Завершён выбор единственной установленной модели и подготовлен вывод по имеющимся техническим и опубликованным данным. Численное сравнение точности двух движков остаётся недоступным до тех пор, пока браузерное распознавание в тестовой среде не завершает запрос и не появится согласованный парный корпус. Неудачный сетевой запрос не считается нулевой точностью браузера.
